# 0과 1, 이진수 탐험대

초등학생 체험 부스용 6단계 이진수 학습 웹앱입니다. 서버, 빌드, 로그인 없이 실행하는 정적 HTML/CSS/JavaScript 앱입니다.

## 실행과 GitHub 업로드

- 개발 소스는 `index.html`을 브라우저에서 엽니다.
- GitHub용 ZIP은 압축을 풀면 `index.html`과 관련 파일이 루트에 있습니다. 내용물을 저장소 루트에 올려 정적 사이트로 게시합니다.
- 단일 HTML 버전은 파일 하나만으로 실행됩니다.
- 여러 태블릿에서는 같은 웹 주소로 접속하는 방식을 권장합니다. 공개 저장소: https://github.com/woohyunssam/2bit20261017

## 학습 흐름

1. 전구의 꺼짐·켜짐으로 0과 1 발견
2. 16·8·4·2·1 자릿값 탐색과 숫자 7 만들기
3. 이진수 읽기: 5, 11, 18, 22의 네 문제
4. 숫자를 이진수로 만들기: 5, 9, 13, 22의 네 문제
5. 읽기·만들기 종합 도전: 6, 10, 19, 25, 31과 별 다섯 개
6. 생일 입력 → 월·일 전구 확인 → 생일 카드 → 두 줄 디폼블록 도안 → 최종 완성

정답 뒤에는 계산 과정을 확인하고 직접 다음 문제로 넘어갑니다. 힌트와 전구 조작으로 다시 시도할 수 있습니다.

## 생일 키링

위쪽 다섯 칸은 월, 아래쪽 다섯 칸은 일입니다. 왼쪽부터 16·8·4·2·1 순서이며 1은 노란색, 0은 검정색입니다. 앞의 0도 포함해 총 10개의 블록을 놓습니다. 도안은 전구·블록 보기 전환과 확대 보기를 지원합니다.

월별 날짜 수를 제한합니다. 연도를 수집하지 않으므로 2월 29일은 허용합니다. 예를 들어 9월 22일은 `01001 / 10110`입니다. 도안의 블록 연결 모양은 안내용이며 실제 제품의 연결부 모양은 다를 수 있습니다.

## 파일 구성

- `index.html`: 시작점과 스크립트 로딩
- `style.css`: 반응형 화면, 전구와 블록 도안, 애니메이션
- `app.js`: 공통 화면, 학생 정보, 1단계, 저장·복원과 단계 연결
- `stage2.js` ~ `stage6.js`: 각 단계의 화면·활동·상태 관리

## 저장과 개인정보

학교, 이름, 진행 상황, 생일의 월·일은 브라우저 localStorage의 `binary-explorer-v1`에만 저장하며 서버로 전송하지 않습니다. 기존 1~5단계 저장 내용도 이어서 이용할 수 있습니다. 같은 이름과 학교로 시작하면 이어서 진행하고, 다른 정보로 시작하면 모든 단계를 초기화합니다.

완성 화면의 ‘다른 생일 만들어 보기’는 앞 단계 완료 상태를 유지합니다. ‘처음부터 다시 체험하기’는 활동과 생일을 초기화하고 학교·이름이 채워진 시작 화면으로 돌아갑니다. 저장이 제한된 브라우저에서는 현재 활동은 가능하지만 새로고침 복원은 되지 않을 수 있습니다. 파일 직접 열기의 저장 지속성은 브라우저에 따라 다릅니다.

Google Fonts가 연결되지 않으면 기기의 기본 한글 글꼴을 사용합니다. 전구는 기기의 이모지를 사용하며 디폼블록은 색과 숫자를 함께 표시합니다. 동작 줄이기 설정을 존중합니다.

## 공통 안내와 이전 이동

guide.js는 로봇 친구 비트의 큰 도움말과 1~6단계 이전 이동 버튼을 제공합니다. 1단계의 이전 버튼은 시작 화면으로 이동합니다. 이동만으로 기존 풀이와 생일을 초기화하지 않습니다. 꺼진 전구의 자릿값에는 대각선이 표시되며, 0/1 자체와 제작 도안의 숫자는 유지됩니다.


## 전구 덧셈 보기

bulb-math.js에서 학습용 전구와 생일 카드 전구를 누르면 아래에 덧셈식과 누적 계산 과정을 보여줍니다. 고정된 문제 전구는 배열을 바꾸지 않고 계산만 확인합니다. 1단계는 자릿값 대신 켜진 전구의 개수를 셉니다. 읽기 문제에서도 전구를 누르면 계산을 확인할 수 있습니다.
